# CI/CD and Automation Setup

This document describes the automated testing and weight management setup for AdaptiVision.

## Overview

AdaptiVision now includes:
1. **Automated cross-platform testing** via GitHub Actions
2. **Automatic weight download** script for easy setup
3. **Multi-platform support** verified on Windows, macOS, and Linux

## GitHub Actions CI/CD

### Test Workflow (`.github/workflows/test.yml`)

**Platforms Tested:**
- ✅ Ubuntu (latest)
- ✅ Windows (latest)
- ✅ macOS (latest)

**Python Versions:**
- 3.8, 3.9, 3.10, 3.11 (macOS excludes 3.8 due to runner limitations)

**What Gets Tested:**
1. Smoke test (`smoke_test.py`)
2. CLI commands (detect, compare, visualize, batch)
3. Example scripts (`examples/batch_processing.py`)
4. Experimental scripts (`scripts/run_experiments.py`)
5. Cross-platform path handling
6. Model weight caching and download

### Features

**Smart Model Weight Caching:**
- Weights are cached across workflow runs
- Only downloaded once per workflow
- Saves ~6MB download per test run
- Cache key: `yolov8n-weights-v1`

**Platform-Specific Download:**
- Unix systems: Uses `curl`
- Windows: Uses PowerShell `Invoke-WebRequest`
- Automatic fallback handling

**Artifact Upload:**
- Test results uploaded for review
- Retained for 7 days
- Organized by OS and Python version

## Automatic Weight Download

### Usage

The `scripts/download_weights.py` script provides cross-platform automatic weight download:

**Basic Usage:**
```bash
# Download default model (YOLOv8 nano)
python scripts/download_weights.py

# Download different model
python scripts/download_weights.py --model yolov8s

# List available models
python scripts/download_weights.py --list

# Force re-download
python scripts/download_weights.py --force
```

### Available Models

| Model | Size | Description | Filename |
|-------|------|-------------|----------|
| yolov8n | 6.2 MB | Nano - Fastest, recommended | model_n.pt |
| yolov8s | 22 MB | Small - Better accuracy | model_s.pt |
| yolov8m | 52 MB | Medium - Best accuracy | model_m.pt |

### Features

**Cross-Platform:**
- ✅ Works on Windows, macOS, Linux
- ✅ Uses Python's built-in `urllib.request`
- ✅ No external dependencies required
- ✅ Progress bar during download

**Smart Detection:**
- Checks if weights already exist
- Verifies file size after download
- Provides helpful error messages
- Cleans up partial downloads on failure

**Integration:**
- Used in GitHub Actions workflows
- Documented in README installation steps
- Works with or without virtual environment

## Weight Management

### Why Weights Are Not in Git

**Model weights are gitignored because:**
1. **Size**: 6.2MB for smallest model (too large for git)
2. **Pre-trained**: Not generated by our code
3. **Upstream source**: Official Ultralytics releases
4. **Multiple options**: Users may want different model sizes

### `.gitignore` Entry

```gitignore
# Model weights
/weights/*.pt
/weights/*.pth
```

### CI/CD Weight Handling

**In GitHub Actions:**
1. Cache is checked first
2. If cache miss, weights are downloaded
3. Weights are cached for next run
4. All tests use cached weights

**Benefits:**
- Faster workflow execution
- Reduced bandwidth usage
- Consistent across test runs
- No manual intervention needed

## Performance Metrics

### Workflow Times (Typical)

| Platform | Setup | Tests | Total |
|----------|-------|-------|-------|
| Ubuntu | ~2 min | ~3 min | ~5 min |
| Windows | ~3 min | ~4 min | ~7 min |
| macOS | ~3 min | ~4 min | ~7 min |

**Note:** First run takes longer due to weight download. Subsequent runs use cache.

### Cache Benefits

**Without cache:**
- 6.2 MB weight download per run
- 11 test configs × 6.2 MB = 68.2 MB per workflow
- ~30 seconds additional time per config

**With cache:**
- Single 6.2 MB download
- Shared across all configs
- ~2 seconds cache restore per config

## Troubleshooting CI/CD

### Common Issues

**1. Weight Download Fails**

**Symptom:** Workflow fails at weight download step

**Solution:**
- Check GitHub Actions logs
- Verify URL is accessible: https://github.com/ultralytics/assets/releases/download/v0.0.0/yolov8n.pt
- Clear cache and retry

**2. Platform-Specific Failure**

**Symptom:** Tests pass on some platforms, fail on others

**Solution:**
- Check platform-specific logs
- Look for path separator issues (/ vs \)
- Verify all paths use pathlib or are cross-platform

**3. Cache Issues**

**Symptom:** Weights download every run

**Solution:**
- Check cache key in workflow
- Verify cache action has correct permissions
- May need to clear and rebuild cache

**4. Test Timeout**

**Symptom:** Workflow times out

**Solution:**
- Check for hanging processes (cv2.waitKey in examples)
- Verify device is set to CPU in CI
- Reduce test dataset size if needed
